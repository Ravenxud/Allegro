# 动画专项方案（0.33）

> ⚠️ **本文档只负责"动效规格"，不负责排期。**
> 权威排期见 [`GLASS_PLAN.md`](GLASS_PLAN.md) 的 P0–P6；性能门槛已随"效果优先"决策作废。
> 本文的 26 项 + GLASS_PLAN 新增的 8 项液态动效 = **共 34 项**，映射关系见 §4。

> 目标：把「能用」变成「手感对」。**不追求炫技**，追求三件事：
> 1. 每个动作都有明确的**起始/结束状态**，不闪、不跳、不残留；
> 2. 交互反馈在 **100ms 内**出现（点下去必须立刻有反应）；
> 3. 60fps 稳定，低端机有降级而不是卡死。

现状盘点：全项目只有 16 处 `tween/spring`，且参数各自为政（120/140/150/160/180/200/220/250/260/320/380 混用）。
这一版先把**设计令牌（duration/easing）统一**，再逐项套用。

---

## 1. 设计令牌

### 1.1 时长

| 令牌 | 值 | 用途 |
|---|---|---|
| `Instant` | 100ms | 按下反馈、颜色切换 |
| `Quick` | 160ms | 小面积进出（图标、徽标、下拉指示器） |
| `Standard` | 220ms | 面板进出、菜单、页面内元素 |
| `Emphasized` | 300ms | 页面级转场、共享元素 |
| `Slow` | 380ms | 仅用于「标签面板」这类大面积缩放 |

### 1.2 曲线

| 令牌 | 定义 | 用途 |
|---|---|---|
| `Standard` | `CubicBezier(0.2, 0, 0, 1)` | 绝大多数进出 |
| `Decelerate` | `CubicBezier(0, 0, 0, 1)` | 只进不出（新内容出现） |
| `Accelerate` | `CubicBezier(0.3, 0, 1, 1)` | 只出不进（旧内容离开） |
| `Spring` | `spring(dampingRatio=0.85, stiffness=380)` | 跟手操作（拖拽释放、下拉回弹） |

> 现有代码已有 `spring(0.85, 380)`，保持；新增一律走令牌常量，不再写字面量。

### 1.3 距离/缩放

- 位移：`8dp`（小元素）、`24dp`（面板）、`1/7 屏宽`（页面级）
- 缩放：`0.96 → 1`（卡片出现）、`0.82 → 1`（标签面板，已有）
- 模糊：仅标签面板背景，`24dp`；低端机降级为纯色遮罩

## 2. 26 项逐条规格

### 包 A：转场与层级（7 项，0.33.0）

| # | 动作 | 触发 | 规格 | 验收点 |
|---|---|---|---|---|
| A1 | 二级页面进入 | 点菜单项 | 从右侧滑入 `1/7` 屏宽 + 淡入，`Emphasized`；背景页缩到 0.94 并变暗 | 无白闪；返回时反向且**不重载网页** |
| A2 | 二级页面返回 | 返回键/手势 | 滑出 `1/9` + 淡出 `Quick`；背景页回弹 `Spring` | 手势中途取消能回弹，不残留半透明 |
| A3 | 返回手势跟手 | 边缘滑动 | 缩放/透明度**线性跟手**（现有 `backProgress`），松手后按速度决定完成或回弹 | 跟手阶段不掉帧；松手无跳变 |
| A4 | 标签面板打开 | 点标签数 | 从缩略图位置放大 `0.82→1` + 背景模糊渐入 `220ms` | 卡片与缩略图位置对齐；低端机改淡入 |
| A5 | 标签面板关闭 | 下拉/点空白 | 缩小 + 模糊渐出 `Quick`；下拉距离跟手 | 下拉跟手；松手按阈值判定 |
| A6 | 应用菜单/长按菜单 | 点菜单 | 底部滑入 `1/4` 高 + 淡入 `Standard`；遮罩 `0→32%` | 连点两次不会叠两层 |
| A7 | 阅读模式进入/退出 | 点阅读 | 共享元素：当前页 → 阅读页（标题+正文位置近似），`Emphasized` | 进入时无明显「换页」跳变 |

### 包 B：列表与状态（9 项，0.33.1）

| # | 动作 | 规格 | 验收点 |
|---|---|---|---|
| B1 | 书签/历史/下载项删除 | `animateItemPlacement` + 高度收缩 `Quick` | 删除后列表不闪、不跳位 |
| B2 | 列表项新增 | 淡入 + 上移 `8dp`，`Standard` | 新项在可视区时不跳动 |
| B3 | 下载进度条 | 线性插值 `Instant`（不追赶，直接缩短差值） | 进度不抽搐；完成时一次快进 |
| B4 | 标签切换 | 内容交叉淡入 `Quick`；工具栏保持不动 | 不出现白屏帧 |
| B5 | 标签关闭 | 卡片缩小 + 淡出，其余卡片补位 `Spring` | 关闭最后一个标签回到首页不闪 |
| B6 | 标签拖拽排序 | 跟手位移 + 其余卡片让位 `Spring`；松手吸附 | 吸附无回弹抖动 |
| B7 | 地址栏聚焦 | 高度/圆角/边框色变化 `Instant`；进度条 `Quick` | 聚焦时页面不被顶动 |
| B8 | 主题切换 | 颜色 `animateColorAsState(Instant)`，不做整屏动画 | 切换无白闪（深色→浅色） |
| B9 | 隐私报告数字 | 数字滚动 `Standard`，上限 800ms 内完成 | 数字变化不抖 |

### 包 C：微交互（10 项，0.33.2）

| # | 动作 | 规格 |
|---|---|---|
| C1 | 按钮按下 | `0.96` 缩放 + 透明度 `0.9`，`Instant` |
| C2 | 收藏成功 | 星标 `1→1.2→1` 弹一下，`Quick` |
| C3 | 复制链接 | 菜单项图标短暂变「✓」，`Quick` 后复原 |
| C4 | 下拉刷新 | 指示器跟手位移 + 释放后回弹 `Spring`；刷新中转圈恒定速度 |
| C5 | 元素选择器 | 高亮框 `2dp` 描边淡入 `Instant`，切换目标时位移插值 |
| C6 | Toast 替代（页内提示） | 从底部 8dp 升起 + 淡入，`Quick`，2s 后自动退 |
| C7 | 桌面版切换 | 菜单项右侧值文字交叉淡入；页面重载时进度条不跳 |
| C8 | 搜索建议/历史出现 | 列表淡入 + 逐项 20ms 延迟（最多 5 项） |
| C9 | 首页进入 | 搜索框 `0.96→1` + 淡入 `Standard`；书签区延迟 40ms |
| C10 | 空态切换 | 图标 + 文案交叉淡入 `Standard` |

### 收尾项（含在上述包里）

- **Reduce Motion 支持**：系统动画缩放为 0（开发者选项/无障碍）时，全部时长压到 `Instant`，只保留透明度变化。
- **低端机降级**：`isLowRamDevice` → 关闭模糊、关闭共享元素、面板改纯淡入（已有 `simplify` 分支，扩展使用）。
- **不做**：Lottie、粒子、3D 翻转、任何需要额外渲染层的效果。

## 4. 动画/材质迭代路线（v2，2026-11 修订）

> 修订原因：P2 实测发现**二级页顶栏无法做玻璃**（Scaffold 的 topBar 不覆盖内容），
> 网页上的菜单也无法模糊（WebView 抓不到）。原计划按"阶段"排，会和"能不能真的看见"脱节；
> 现改为**按可视性排序**：先做一定能看见的，再攻需要快照的结构难题。

### 4.1 现状

| 版本 | 内容 | 状态 |
|---|---|---|
| 0.33.0–0.33.3 | SDK 基线（minSdk 33 / targetSdk 36）、Backdrop 接入、AGSL/Backdrop 真机验证 | ✅ |
| 0.33.4 | `Motion.kt` 令牌 + 15 处裸 tween 收敛 + `appGlass` 骨架 | ✅ U1 成立 |
| 0.34.0–0.34.2 | 底栏 scrim ✅；菜单在首页真玻璃 ✅；二级页顶栏玻璃 ❌ 已撤销 | 部分 |

### 4.2 后续路线（按"多快能看见"排序）

| 版本 | 主题 | 内容 | 可见 | 工量 |
|---|---|---|---|---|
| **0.34.3** | 首页玻璃化 | 搜索卡 / 书签卡 / 最近关闭卡改成玻璃（首页是纯 Compose，模糊一定生效）；C9 首页入场 | ✅ 第一眼 | 1 天 |
| **0.35.0** | 网页快照模糊 | `SnapshotBlurController`（PixelCopy 抓区域 ≤720px、150ms 去抖、1.5s 保鲜、视频全屏禁用）；网页上的底部菜单/长按菜单改真玻璃 | ✅ 常用交互 | 2–3 天 |
| **0.35.1** | 二级页顶栏玻璃 | 10 个二级页改"内容穿透栏下 + `contentPadding.top`"；顶栏 `appGlass`；A1/A2 转场同步换令牌 | ✅ | 1.5 天 |
| **0.36.0** | IOR 液态玻璃（P3） | 自研 AGSL 折射 + 色散 + 噪声替换 `lens()`；L1 按压凹陷、L2 滚动视差、L4 色散呼吸 | ✅ 质感 | 2–3 天 |

| **0.37.0** | 转场与列表动效 | 包 A 剩余（A3 跟手、A6 菜单、A7 阅读近似）、包 B（B1–B3 增删/进度、B5 关闭、B6 拖拽、B9 数字）、B4/B7/B8 | ✅ | 2–3 天 |
| **0.37.1** | 微交互与收口 | 包 C（C1–C8/C10）、L8 主题过渡、Reduce Motion、`GlassQuality` 外观页 + baseline profile + R8 校验 | ✅ | 1.5 天 |

### 4.3 与 34 项的对应

- 已落地：令牌体系（P1）+ 底栏 scrim + 首页菜单玻璃
- 上表 0.34.3–0.37.1 覆盖剩余全部 31 项；每版只做"能当场截图证明"的部分
- 明确交叉依赖：**0.35.0 的快照能力是"网页上做玻璃"的唯一前提**；
  **0.35.1 的结构改造是"二级页顶栏"的唯一前提**；两者都不做，后续只会有"半透明"

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| `AnimatedVisibility` 首次组合即 true 不播动画 | 二级页第一次进入无动画 | 已有 `MutableTransitionState` 方案，统一套用 |
| 模糊在低端机掉帧 | 面板卡顿 | `isLowRamDevice` 直接关模糊 |
| 动画期间点按穿透/丢失 | 点了没反应 | 动画期间保留点击（除遮罩层），或提前结束动画 |
| 共享元素在 WebView 上不可行 | A7 无法真正"共享" | 用「同位置淡入淡出 + 标题位移」近似，不做真共享 |
| 页面重载与动画竞争 | 白闪 | 转场动画不等待加载，加载中显示骨架条 |

## 6. 与其他版本的边界

- 不做 WebView 内部的滚动/缩放动画（属内核行为）
- 不做列表虚拟化改造（0.36 稳定性专项处理）
- 不做图标/插画资源（外观专项）
