# 测试与验收

## 自动化

```bash
gradle --no-daemon testDebugUnitTest
```

| 测试类 | 条数 | 覆盖 |
|---|---|---|
| `UrlParserTest` | 5 | 协议透传、裸域名补 https、IP/localhost、中文与空格转搜索、空输入 |
| `FilterEngineTest` | 9 | 域名/子域拦截、误伤防护、@@ 例外（含路径）、片段规则、同站忽略片段、cosmetic 合并 |
| `BookmarksHtmlTest` | 4 | 导出→解析数量一致、转义往返、文件夹归属、无文件夹平铺导入 |
| `HomeDateTest` | 2 | 日期格式化不抛异常、问候语边界 |

**缺失**：instrumentation 测试、UI 截图测试、性能基线（Macrobenchmark）。

## CI

`.github/workflows/build.yml`：push 到 `main` → JDK 17 → 手动装 cmdline-tools → `testDebugUnitTest` → `assembleDebug` → 上传 artifact。
> 未包含 lint（本地环境缺 `lint-gradle`，需在 CI 补 job）。

## 已知无法自动验证的部分

- 真实网页的 CSS/JS 兼容性（需真机 + 具体站点）
- 手势冲突（下拉刷新 vs 页面滚动，特别是虚拟滚动站点）
- 后台保活、内存压力下的 WebView 回收
- 不同厂商 ROM 的 WebView 差异
