## 长描述

**轻，但不将就。**

Allegro 是一个把"该有的都有、不该有的都没有"做到极致的 Android 浏览器：
安装包不到 2MB，没有账号体系，没有统计 SDK，没有推送，也没有"猜你喜欢"。

**浏览**
- 标签页最多 4 个 WebView 常驻，切换不重载；超过后自动冻结，回来即恢复
- 地址栏智能识别网址与搜索词；支持深链、系统分享、PROCESS_TEXT 划词
- 下拉刷新自己实现，虚拟滚动站点会主动禁用，避免和页面滚动打架

**安静**
- 广告过滤：内置规则 + 可订阅源，主文档永不拦截；支持按站点暂停
- 隐私报告：拦截总数、覆盖域名、域名 Top 20，全部在本机统计
- 元素选择器：点一下广告块就永久隐藏，不用写规则

**阅读**
- 阅读模式（Mozilla Readability + 后处理 + 长文拼页）、系统 TTS 朗读
- 离线页：保存为**自包含单文件 HTML**，断网也能看，图片样式一并带上

**按站点做主**
- 每个域名可单独控制 JavaScript、图片、桌面版 UA、广告过滤
- 一键清理本站 Cookie 与本地存储

**数据是你的**
- 书签/文件夹/站点设置/偏好可通过**任意 WebDAV**（坚果云、Nextcloud、群晖、自建）同步
- 书签可导入导出 Netscape HTML，与 Chrome/Firefox 互通
- 无云端账号，服务器地址与密码只存在你的设备上

**克制**
- 没有资讯流、没有壁纸商城、没有会员
- 全部功能离线可用（除网页本身）
